## Правила пользователя

- Для крупной задачи при большом контексте использовать отдельный свежий чат. Завершить срез, проверки, содержательный commit и push перед передачей.
- Для каждой следующей задачи открывать отдельный чат с **model `gpt-6.1-terra`, thinking `ultra`**, по последнему запросу пользователя. Глобальную модель не менять.
- Чаты собирать в разделе боковой панели **Space Client**; находить актуальный sectionId через list_threads, избегать дубликатов. Исходный чат «Изучить клиенты и составить план» уже перенесён туда.
- Работать с существующим репозиторием. Новый чат не переносит автоматически рабочую папку или всю историю: передавать абсолютный путь и этот документ.
- Читать AGENTS.md, README.md, этот файл и документ задачи. Codebase Memory использовать для поиска архитектуры/символов с проверкой покрытия/свежести. При недоступности сервиса пользоваться исходниками и записывать ограничение.
- Не использовать Computer Use, не открывать видимые приложения и не перехватывать фокус: пользователь работает на этом ПК. Проверки запускать в фоновом или headless-режиме.
- Сайт пока локальный. Для входа выбраны локальный ник и будущая Space-регистрация; Microsoft отложен. Локальный запуск SC-25 работает, Space-регистрации и установщика нет.
