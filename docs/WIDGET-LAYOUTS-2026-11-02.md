# Keystrokes и компактный ToggleSprint HUD · 2 ноября 2026

Keystrokes получил **Content → Layout → Block**: W над A/S/D, отдельная широкая клавиша прыжка и ряд attack/use. Показываются фактические назначения Minecraft, включая переназначение действий. Прыжок и мышь по-прежнему отключаются отдельно; пустые ряды исчезают. Ячейки имеют скруглённый фон, нажатие выделяется выбранным цветом HUD с тёмной подписью. Backdrop/цвет/тень учитываются; при Background Off у ненажатых клавиш нет заливки, подсветка нажатия остаётся. Длинные названия сокращаются, ширина блока ограничена и не меняется при нажатиях. Потеря фокуса и меню по-прежнему убирают pressed-состояние.

**ToggleSprint HUD → Content → Display style → Compact** включает скруглённый индикатор с точкой и краткой подписью: OFF, ON / READY, ON / RUN. Если модуль выключен, отображается OFF; если ручной спринт продолжается при невооружённом toggle, текст явно показывает OFF / RUN. Точка серая для выключенного/невооружённого режима, золотая для готовности, зелёная для вооружённого фактического спринта. Включение модуля не выдаётся за движение игрока.

Строковый Keystrokes и полный ToggleSprint сохранены по умолчанию и при миграции. Форматы независимы для двух HUD-профилей. После выбора блока его расположение можно изменить через **Edit layout**: более высокая раскладка может потребовать места среди уже расставленных виджетов.

Настройки используют настоящий рендерер виджета в предпросмотре, включая все ячейки и компактный статус. Предпросмотр вписывается в выделенную область, не меняя сохранённый масштаб. Редактор учитывает полные ширину и высоту при hit testing, drag, nudge, anchor, fitting и snapping. Отключённые невыбранные виджеты скрыты и не перехватывают клики; выбранный выключенный виджет остаётся доступен для настройки. Панель управления использует свободное место над/под высоким блоком, в том числе с меньшим отступом от края; если виджет занимает почти весь маленький экран, полностью разнести панель и виджет физически невозможно.

HUD schema **13**, export **v8**. Поддерживаются схемы 1–12 и экспорты v1–v7, перед первой записью миграции создаётся проверенная копия. Реальные fixtures schema12/exportv7 получены прежним сериализатором JAR `57e1593` без пользовательских данных. Проверены сохранение новых форматов, старых настроек и размещений, независимость профилей, отказ от неполных/неизвестных значений и отсутствие сброса новых параметров при редактировании старых.

Прошли **160 Java-тестов и 112 тестов лаунчера**, TypeScript, Prettier затронутых файлов лаунчера, сборка и строгая проверка JAR/source stamp. Геометрические проверки включают все комбинации дополнительных рядов, длинные подписи, pressed-state, привязки, границы и панель редактора. [Машинные результаты](qa/widget-layouts-2026-11-02.json).

В невидимом Minecraft Canvas открыт только ранее созданный QA-мир. Реальными методами экранов проверены переключение Block/Compact, включение/отключение рядов, фактическая подпись переназначенной клавиши, полный размер editor bounds, четыре anchor, nudge, захват нижнего ряда и drag далеко за границу с последующим clamping. Проверены отсутствие клика по скрытому виджету, независимость профилей и чтение сохранённого файла. В мире отображён действительный ON / READY при включённом AutoSprint без движения. Отдельный кадр рендерера содержит явно заданные sample pressed states и длинную подпись; он не доказывает физический ввод. Пять framebuffer-снимков 1280×720 осмотрены; финальный QA завершён с кодом 0, ошибок Mixin/текстур не наблюдалось. Физический ввод не проверялся, FPS не измерялся, RUN в движущемся мире в этом срезе не принимался.

Проверенная сборка установлена в закрытый пользовательский инстанс `.reports/launcher-desktop`. Проверка запуска пройдена; options, существующие HUD/mod/browser-настройки и level.dat не изменились при установке. Игру после обновления не запускали.
