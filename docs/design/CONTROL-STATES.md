# Space / Controls

Обновление Eclipse: сайт и JSON теперь используют янтарные/медные цвета и мягкий белый текст. Поведение и размеры ниже сохранены; лавандовая Figma-витрина описывает предыдущий срез и пока не обновлена. [Текущая тема](ECLIPSE.md).

Срез 24 октября 2026, часть SC-17. Сохраняем Nebula, русскую типографику и существующую композицию. Цель — согласовать поведение элементов управления на всех страницах.

| Элемент | Default | Hover | Pressed | Focus | Disabled / busy |
|---|---|---|---|---|---|
| Primary | Лавандовый градиент, тёмный текст | Светлее, мягкое свечение | Более плотный градиент, inset, без сдвига layout | Видимый контур 2 px с отступом | Матовая поверхность; hover/pressed и движение исключены; busy имеет текст и aria-busy |
| Secondary | Тёмная поверхность, читаемая граница | Светлее поверхность и граница | Более плотная поверхность | Тот же контур | Те же правила disabled |
| Input / select | Единая высота 52 px и контрастная граница | Подсветка границы | Нативное редактирование/выбор | Акцентная граница и контур | Приглушённая поверхность, читаемый текст |
| Read-only | Остаётся выделяемым и копируемым | Без обещания редактирования | Нативное выделение | Видимый контур | Не заменять disabled: SHA-256 должен выделяться |
| Error | Текст объяснения рядом, связь aria-describedby и aria-invalid | — | — | Контур сохраняется | Не передавать ошибку только цветом |

Поиск с активными параметрами показывает сброс рядом с числом результатов, в том числе при непустой выдаче. URL остаётся источником применённых фильтров. Наведение не требуется для действия. Системное reduced-motion отключает переходы.

Базовые Button/Input показывают стандартный размер 52 px. Компактная область SHA-256 сохраняет прежний monospace 12 px и кнопку копирования минимум 44 px; её отдельный компонент не входит в эту витрину. Поисковые поля и select используют 16 px. Этот срез не объявляет все существующие элементы сайта экземплярами одной Figma-библиотеки.

Foundations остаются в space-dark.tokens.json. Дополнительные значения control-states.tokens.json предназначены для отдельной коллекции **Space / Controls**. CSS генерируется из обоих файлов; проверка дрейфа и численных контрастов выполняется до сборки. Текст — минимум 4.5:1 для проверяемых пар, границы и focus — минимум 3:1 на указанных тёмных поверхностях. Это проверка конкретных цветов, а не сертификация всей доступности сайта.

В [Figma](https://www.figma.com/design/rlT7ixlB1AVZVvp9BfRLZJ/Space-Client-Website-Design?node-id=23-61) добавлены native component sets **Space / Button** (Style × State, 12 variants) и **Space / Input** (6 states), два общих текстовых стиля и три стиля теней. Витрина содержит экземпляры компонентов; основные компоненты находятся отдельно. Цвета, в том числе точки градиентов, границы, padding, gap, высота и радиусы связаны с переменными. Label, Busy label и Value доступны как component properties. В Figma используется Inter: Segoe UI отсутствует в доступных шрифтах; сайт сохраняет системный Segoe UI. Это явное различие шрифтов, а не обещание совпадения пиксель в пиксель.

Коллекция Controls содержит 15 переменных; четыре совпадающих значения ссылаются на Foundations через aliases. Для Foundations настроены области применения и WEB code syntax без изменения значений. У timing-переменной Figma не поддерживает назначение scopes; для остальных используемых переменных ALL_SCOPES исключён. Пробная Collection 1 не используется.

Команды: `npm run tokens:web` генерирует CSS, `npm run tokens:web:check` проверяет дрейф и 20 пар контрастов после добавления navigation.tokens.json. CI проверяет токены до сборки. Browser QA проверяет настоящий hover/press, геометрию, клавиатурный фокус, сброс непустой выдачи и отсутствие hover-эффектов на disabled/busy при повторе запроса. Новые компоненты навигации имеют отдельный [статус черновика](NAVIGATION.md); они не входят в принятую витрину Controls.

Срез проверяется в облачном файле через Figma MCP; прежняя локальная FIG-копия остаётся резервной копией предыдущего состояния и не включает эти компоненты. SC-17 остаётся открытой: ещё нужны остальные повторяемые компоненты и полная приёмка всех макетов.
