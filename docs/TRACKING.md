# Отслеживание задач

Трекер: [GitHub Issues](https://github.com/AdilSatuv/spaceclient/issues). Отдельный платный сервис или аккаунт не нужен. Начальный общий план: SC-01…SC-15. Приоритетная веб-очередь: SC-16…SC-24, отдельный milestone W. P0 — критично для текущего среза; P1 — следующая обязательная часть MVP. Зависимости и критерии находятся в каждой задаче.

- [Подробный план](IMPLEMENTATION-PLAN.md).
- [Ссылки на все задачи](TASKS.md).
- [Этапы и их прогресс](https://github.com/AdilSatuv/spaceclient/milestones).

Пользователю достаточно открыть Issues, выбрать milestone и читать checklist. Закрытые задачи можно посмотреть через фильтр `is:issue is:closed`. Изменения связаны с задачами через ссылки в сообщениях коммитов.

## Установленная программа

Официальный GitHub CLI 2.103.0 установлен локально в `.tools/gh/bin/gh.exe`, архив проверен по SHA-256 из официального релиза. Глобальный PATH не менялся.

```powershell
./scripts/install-github-cli.ps1
node scripts/github.cjs issue list --repo AdilSatuv/spaceclient
node scripts/github.cjs issue view 2 --repo AdilSatuv/spaceclient
```

`github.cjs` использует существующий GH_TOKEN/GITHUB_TOKEN или Git Credential Manager. Учётные данные передаются только дочернему процессу в памяти, не сохраняются в файлы или Git. Без готового доступа команда завершится ошибкой; новые токены без участия пользователя не создаются.

## Изменение плана

Исходные ID, приоритеты и критерии — в `docs/tasks.json`. Для создания недостающих задач:

```powershell
node scripts/sync-tasks.cjs
```

Скрипт находит созданные задачи по служебному ID в body, учитывает пагинацию и не переписывает существующие задачи или их статус. Затем обновляет TASKS.md. Редактирование критериев уже созданной задачи нужно выполнять явно в GitHub; JSON не является двусторонней синхронизацией.

Задачи закрываются только после проверок. Если код есть, а поведение в игре не проверено, задача остаётся открытой. Статус «заблокировано» объяснять конкретной зависимостью. Никаких пустых задач или коммитов ради contributions.
