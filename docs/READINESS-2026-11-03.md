# Готовность Space Client · аудит 3 ноября 2026

**Продолжение аудита:** приоритет 1 выполнен — core, UX/UI и настройки объединены, проверены вместе и установлены локально. [Итог интеграции](INTEGRATION-2026-11-03.md). Ниже сохранён исходный срез аудита до объединения.

**Вывод: проект является рабочим локальным прототипом. Готовность к выдаче обычным пользователям и публичному релизу пока не подтверждена.** Каталог из 55 модулей и успешная сборка не означают полной приёмки каждого режима, сетевой игры, установщика и обновлений. Проценты готовности не назначались: у разных частей разные критерии завершения.

Проверена основная копия `space-client-minecraft-menus/work/spaceclient-menus`, ветка `space-minecraft-menus`, snapshot `e7f85094b6326b6c74ebc323e191945a4b621a0a`. Проверены код, установленные байты, свежие тесты/сборки, отчёты игрового QA, отдельные рабочие копии и статусы трёх чатов, GitHub Issues/Actions/releases. В этом аудите Minecraft не запускался, пользовательские профили и миры не менялись, ветки не объединялись, push/публикация не выполнялись.

**Проверки этого аудита**

- `npm test`: **39 общих +24 API +112 launcher =175**, все прошли. Java: **249**, сборка/проверка Gradle успешна, задачи up-to-date для неизменённого game tree. Итого **424 автоматических теста основной версии**; браузерные сценарии считаются отдельно.
- TypeScript всех workspace, проверка токенов и полная сборка API/сайта/лаунчера прошли. Launcher build выполнялся с `SPACE_REQUIRE_GAME_BUNDLE=1`.
- Launcher hidden UI: 10 checks, 14 generated screenshots, rendererErrors пусты; свои данные QA, без настоящих аккаунтов/скачиваний/игры. Этот аудит не выдаёт все сгенерированные кадры за новый полный визуальный просмотр.
- Сайт: восемь HTTP-сценариев прошли. Первый Chrome-прогон завершился `ERR_CONNECTION_REFUSED` на `/download` в no-JavaScript сценарии после 42 layouts и 23 flows; page errors пусты. Повтор с добавленным наблюдением своего Next child прошёл **42 layouts /27 flows**, errors/skipped пусты. Его SIGTERM — штатная очистка после успешного отчёта. Причина первого отказа не установлена; сбой не объявлен доказанным дефектом сайта и не скрыт успешным повтором. Новый Firefox-прогон, Lighthouse/HTTPS и screen-reader QA не выполнялись.
- Сырой Windows `format:check` завершился с ошибкой в 189 файлах. Проверка текста тех же файлов с нормализованными LF прошла для **всех 189**; других расхождений форматирования не обнаружено. Это несогласованность line endings/проверки на Windows, а не 189 подтверждённых дефектов кода. Глобальные Git-настройки не менялись.
- Bundle/установленный JAR совпадают: SHA-256 `752512a6368b24750eca956db7a1687f5b866e30fd8ff76b98350d33596e4738`, game tree `541aae11fe5c1213ea84cdd545723b34fc3bc990`, 1 062 009 байт. Предыдущий native QA связан с тем же tree/hash, а не с похожим по названию JAR.

**Следующие задачи — в порядке важности**

1. **P0 — собрать единую версию из готовых направлений.** Сначала core-исправления отмены/ошибок, затем UX/UI, затем завершённые настройки всех 55 модулей. Сохранить новые enums/schemas/mixins. Критерий: совместные тесты/сборки/QA проходят на одном commit, исправление aborted probe подтверждено, bundle stamp и установленный SHA совпадают. Отдельные зелёные ветки не считаются готовой объединённой версией.
2. **P0 — принять текущие модули в реальной игре.** Матрица для всех 55: физические input/hold/rebind, GUI scale/Unicode, F1/F3, открытие экранов, смерть/respawn, смена мира/dimension, выход и переподключение. Особый приоритет FreeLook/ToggleSprint/Zoom/Snaplook/Auto Text/Tooltips/Dynamic FPS и совместной работе GL-эффектов. Затем контролируемый тестовый сервер. Критерий: у каждой функции записаны поддержанные сценарии, результат и остаточные ограничения; client estimates явно помечены.
3. **P1 — устранить проблему определения актуальной сборки и обновления.** Показать различимый build ID в лаунчере и игре вместо одного `0.1.0`, связывать его с проверенным bundle. Подготовить обновление/восстановление/rollback с сохранением профилей и миров. Критерий: можно однозначно увидеть запущенную версию и повторить переход со старой на новую без ручной подмены JAR.
4. **P1 — проверить полный путь на чистой Windows.** Свежий setup с актуальным JAR, выбор/подготовка Java, скачивание файлов, локальный запуск, создание мира, повторный запуск, repair, upgrade и удаление приложения с сохранением пользовательских данных. Условия новой/занятой папки, Unicode/пробелов, отмены и отсутствия места. Критерий: проверяемый пользовательский сценарий без зависимости от нашей `.reports` и локального JDK разработчика. Связано с SC-14.
5. **P1 — измерить производительность актуального набора.** Непрерывный сопоставимый vanilla / Space off / типичный набор / blur+particles, frametime P95/P99, 1% low, память, startup и длительная смена миров. Критерий: воспроизводимые исходные данные и понятные presets; никаких обещаний ускорения до измерений. Старый отчёт SC-13 не переносится на 55 модулей.
6. **P1 — стабилизировать совместные проверки.** Разобрать первый отказ веб-прогона, сохранять вывод/exit тестового сервера, согласовать Windows LF policy. Подготовить CI точного объединённого commit перед alpha. Критерий: одинаковые проверки воспроизводятся на Windows и CI, сбой даёт причину, а не только повторный запуск. Публикацию ветки выполнять только в рамках разрешённой пользователем политики.
7. **P2 — синхронизировать сайт и документацию с продуктом.** Каталог фактических модулей и их ограничений, changelog текущей сборки, инструкции обновления/совместимости, устранение старых чисел в README/ТЗ. Реальные download/release данные добавлять после приёмки артефакта. Критерий: сайт и лаунчер описывают ту же проверенную версию; действительное отсутствие релиза остаётся явным.
8. **Отложенные релизные блоки — аккаунты и публичное размещение.** Для официального онлайн-сценария отдельно завершить регистрацию приложения и полный Microsoft/Xbox/Minecraft вход с entitlement/profile/refresh/logout; решение о Space-регистрации остаётся продуктовым. После готовности артефакта — релизный каталог, HTTPS/domain/health/rollback. Это ранее отложено пользователем и не запускалось автоматически данным аудитом.
