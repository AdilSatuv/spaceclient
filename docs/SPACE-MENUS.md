# Меню Minecraft в стиле Space

Изолированный локальный срез от `bf662f3`, 28 октября 2026. Пользователь утвердил графитовые поверхности, сдержанный золотой акцент и типографику существующего HUD. Название проекта не менялось. Этот срез не опубликован и не является игровой приёмкой.

## Реализация

- Главное меню: центральная графитовая панель, золотая основная кнопка одиночной игры, читаемые вторичные действия, текстовая кнопка выбора языка. Подписи действий поступают из Minecraft I18n. Существующие одиночная/сетевая игра, Realms, настройки, выход и demo-действия используют исходный `TitleScreen.buttonClicked`; новые сервисы или фиктивные разделы не добавлены.
- Пауза, выбор/создание/редактирование мира, серверы, настройки, язык, управление, видео, звук, наборы ресурсов и LAN используют общий фон и оформление стандартных кнопок. Списки, текстовые поля, ползунки, назначения клавиш и специализированные виджеты оставлены штатными. Цвета/шрифт меню не заменяют игровой HUD или текст чата.
- Главное меню и пауза: Tab/Shift+Tab, стрелки вверх/вниз, Enter/Space; фокус обходит только видимые доступные обычные кнопки в порядке сверху вниз и слева направо. На паузе Esc по-прежнему возвращает в игру. События форм и списков не перехватываются.
- Компоновка пересчитывается при штатной инициализации/resize. От 240×220 scaled GUI применяется новая компоновка, ниже — исходная. При штатном предупреждении о старом OpenGL сохраняется исходный экран вместе с текстом и кликабельной областью предупреждения.
- Жизненный цикл Realms и отрисовка уведомлений сохранены. Шрифт — существующий `SpaceUiFont` с bundled DejaVu Sans, Unicode/vanilla fallback и ограниченным кешем. Нет фоновой анимации или дополнительной загрузки assets.
- Лаунчер проверяет точный набор из девяти mixin-классов, включая три новых; строгая проверка повреждённых/неизвестных классов не ослаблена.

## Проверки и ограничения

`scripts/game.ps1 test build --offline`: 86 Java-тестов, включая геометрию на 42 сочетаниях scaled GUI-размеров (пять и шесть кнопок), обход фокуса и наличие injection target signatures в закреплённых mappings. `node --test apps/launcher/test/*.test.cjs`: 110 тестов. `npm run check --workspace @space/launcher`: TypeScript без ошибок. Изменённые TypeScript/CJS проверены Prettier; `git diff --check` выполнен.

Проверка сигнатур не подтверждает runtime-применение mixin. Minecraft и видимые приложения не запускались; OpenGL, реальные переходы между экранами, уведомления Realms, мышь/клавиатура, Unicode/resource-pack fallback и визуальная матрица GUI scale в игре остаются непроверенными. Minecraft 1.8.9 не получает screen-reader/narrator API от этого среза; улучшения доступности здесь — читаемый текст, текстовые подписи и видимый клавиатурный фокус.

Следующая игровая проверка после разрешения пользователя: главное меню → миры → назад; multiplayer → direct/add server → cancel; настройки → язык/видео/звук/управление → назад; пауза → HUD/Mods → Esc; GUI scale Auto/Normal и resize; demo/old-GL fallback и Realms. Не создавать, не удалять и не переименовывать пользовательские миры ради проверки.

Рабочая копия и локальные инструменты независимы от исходного HUD checkout и общего SC-27 checkout. Origin удалён только из новой копии, чтобы исключить случайный push в исходный локальный репозиторий. Пользовательские миры, игровые настройки, открытые приложения и системная конфигурация не менялись.
