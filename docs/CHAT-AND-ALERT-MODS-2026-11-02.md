# Chat Timestamps и Durability Warning · 2 ноября 2026

Добавлены два opt-in модуля: теперь 11 игровых + 23 HUD = 34 карточки. Открыть правым Shift и найти по названию; Chat Timestamps находится также в Misc, Durability Warning — в Player и Misc. Оба выключены по умолчанию, Toggle key не назначены. Избранное, поиск, сохранение и плавные переключатели используют существующий каталог.

Chat Timestamps добавляет к новым сообщениям локальное время получения: `HH:mm`, `HH:mm:ss` или `hh:mm AM/PM`. Время фиксируется при поступлении; старые строки не переписываются при включении, отключении, смене формата или повторном переносе строк. Цвет, форматирование, команды по клику и hover исходного текста сохраняются в копии. Серый префикс не наследует команды. Мод не отправляет сообщения и не добавляет историю на диск; штатный локальный Minecraft log получает уже украшенный текст. Штатные ID и замена сообщений остаются в управлении Minecraft.

Durability Warning показывает тихую плашку сверху по центру при прочности ≤5%, ≤10% или ≤20% (по умолчанию 10%). Проверяются четыре надетых предмета брони и предмет в выбранной руке. При нескольких проблемных предметах показывается наименьшая доля прочности с числом оставшихся использований. Имя сокращается отдельно от чисел. Сравнение точное, без раннего срабатывания из-за округления. Здоровые, пустые, неразрушаемые и не выбранные предметы не вызывают предупреждение. Оно исчезает после смены/починки предмета и скрывается в GUI, при F1/F3, выключенном master HUD, смерти или чужой камере. Нет звуков, повторных сообщений или изменения предметов. Положение фиксированное; это игровой модуль, а не перемещаемый виджет редактора.

Mods schema 7: 42 поля; чтение 1–6 сохранено. Реальный fixture `mods-schema6-bb5739c.properties` получен старым сериализатором из предыдущего JAR до изменения исходников. При открытии старый файл не переписывается. Новые модули выключены и не забирают прежние клавиши. Reset сбрасывает только настройки/Toggle key выбранного модуля, оставляя его Enabled. Ошибочные и будущие файлы сохраняются read-only; неудачная запись откатывает изменение. HUD schema17/export12 и browser schema1 не менялись. ## Проверки

216 Java + 112 launcher tests, TypeScript, Prettier, game build и строгая launcher bundle build прошли. Источники: `0c2c0f5`; pin привязан к `HEAD:game`. Результат фоновой игровой проверки, хеши снимков и установки — [QA](qa/chat-alert-mods-2026-11-02.json).

Native QA использует отдельный скрытый Canvas 1280×720 и только ранее созданный QA-мир. Проверяются реальные карточки/поиск/настройки, отказы занятых клавиш и сохранение свободных, все форматы/пороги; настоящий ChatHud с новыми строками, ID replacement, стилями, click/hover, повторным переносом и выключением. Для предупреждений заданы клиентские образцы брони/инструментов: рука, только броня, смена, здоровый предмет, не выбранный слот, Unbreakable, пороги и скрывающие контексты. Проверены GL state/cache и неизменность NBT образцов; параметры Minecraft не меняются. Шесть полученных кадров осмотрены; финальный тестовый процесс завершился с кодом 0.

В первых попытках исправлен только disposable QA: изначально назначалась занятая `/`; затем тест ожидал сохранения временной ID-строки после native reset, хотя vanilla удаляет её при переносе. Теперь replacement и перенос обычных строк проверяются отдельно. Повтор после неудачного чтения UTF-8 файла остановлен до завершения. Затем исправлена только кодировка Unicode-образца в QA и повторно выполнена серия. Production код при этих исправлениях не менялся. Останавливались только собственные тестовые Java-процессы.

Не проверены физический ввод, серверные пакеты multiplayer, полный набор resource packs/shaders и производительность. Вызовы ChatHud и инвентарные образцы подаются напрямую в тестовом клиенте; это не доказательство полноценной сетевой совместимости. Пользовательская игра после установки не запускается, миры не открываются.
