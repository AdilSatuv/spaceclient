# Меню модулей HUD — SC-04

Срез 24 октября 2026. Сборка и полная матрица меню в мире Minecraft 1.8.9 выполнены; закрытие SC-04 фиксируется после CI точного SHA в issue #4. Локальный запуск из лаунчера принят в SC-25; Space-регистрация и Microsoft-вход ещё не реализованы. SC-02/03 приняты.

## Управление

- **Правый Shift** открывает меню в мире и закрывает его следующим отдельным нажатием (перенесено с F9 по просьбе пользователя). Удержание не переключает повторно. В главном меню и других экранах клавиша игнорируется. Левый Shift сохраняет обычное игровое назначение.
- **Space HUD** в меню паузы открывает тот же экран мышью. Кнопка занимает свободную строку между Achievements/Statistics и Options/LAN; Done/Esc возвращают в мир.
- **F8** переключает общую видимость HUD вне меню.
- Поиск фильтрует FPS, Coordinates, Keystrokes и CPS по названиям и английским/русским ключевым словам. Пустой результат имеет отдельное состояние.
- Карточка включает или выключает один модуль; общая видимость сохраняет индивидуальный выбор.
- **Tab / левый Shift+Tab** обходят поиск, общую видимость, отфильтрованные карточки и Done. Из поиска **Down / Enter** переводит фокус на первый результат. **Space / Enter** активируют выбранный элемент; повторные key-down не переключают его повторно.
- **Esc / Done** возвращают в мир. Изменения сохраняются сразу, отдельной кнопки Apply нет.

Экран использует тёмную Eclipse-палитру с янтарным фокусом. ON/OFF обозначены текстом. Мир в singleplayer приостановлен; пауза multiplayer-сервера не подразумевается. В меню CPS очищается, события мыши не учитываются как игровые.

## Границы кода

| Часть | Ответственность |
|---|---|
| `hud/HudModule` | Четыре стабильных ID, метаданные, поиск, доступ к флагам схемы 1; без Minecraft |
| `HudConfig` | Ограниченное чтение/проверка properties, уникальный временный файл, atomic move с fallback |
| `hud/HudSettings` | Загрузка/восстановление, команды, откат при ошибке записи и сообщения; без Minecraft |
| `hud/HudModulesScreen` | Minecraft Screen: геометрия, отрисовка, мышь, фокус и клавиатура |
| `mixin/ClientMixin` | Наблюдение F8/правого Shift и игровой мыши, без собственного цикла Mouse.next |
| `mixin/GameMenuMixin` | Одна кнопка в паузе; открывает существующий HudModulesScreen, без собственных настроек |
| `KeyPressGate` | Один right-Shift press на событие, защита от повторного dispatch после изменения Screen и от repeat; без Minecraft |
| `mixin/HudMixin` | Отрисовка выбранных модулей, без правил сохранения |

ClickCounter остаётся отдельной моделью. Редактор размещения, масштаб и HUD-профили относятся к SC-05 и ещё не реализованы. Статические позиции HUD пока прежние.

## Сохранение

Dev-конфиг: `game/run/config/spaceclient-hud.properties`. Схема 1 и имена флагов сохранены; отсутствующие настройки получают прежние defaults. Лимит 64 KiB проверяется при чтении потока.

Невалидный boolean, повреждённый Unicode escape или превышение лимита переводят исходный файл в уникальный `*.invalid-<uuid>.bak`. После успешного резервирования используются defaults, меню показывает уведомление. Ошибка резервирования/чтения включает read-only; исходный файл остаётся на месте. Более новая схема также read-only, без переименования/перезаписи.

При отказе записи флаг возвращается в предыдущее состояние. Меню показывает `Could not save. Change reverted; try again.` Успешная повторная запись очищает ошибку. Временные файлы очищаются. HUD-конфиг отделён от launch-профилей.

## Подтверждённые проверки

`./scripts/game.ps1 build`: **19 тестов** — 4 HudConfig, 5 ClickCounter, 10 HudSettings/поиска. Новые проверки: независимость модулей, перезапуск, master visibility, точное сохранение повреждённого файла в backup, malformed Unicode, лимит размера, будущая схема, ошибка чтения, откат обеих команд, повторная запись и Turkish locale.

Через Computer Use в настоящем dev-мире: окно 854×480, GUI Auto (427×240 GUI units), Temurin 21.0.12.1 / Loader 0.18.3:

- F9 открывает экран; четыре карточки, поиск, статус и Done помещаются без перекрытий.
- Поиск по кириллической `м` оставляет CPS (ключевое слово «мышь»); несуществующий запрос показывает No modules found; очистка возвращает все модули.
- Down переносит фокус с поиска на CPS; Space меняет ON на OFF. Esc закрывает экран, CPS исчезает, остальные данные остаются.
- Мышью выключены FPS, координаты и клавиши. Done возвращает в мир: остаётся только SPACE CLIENT.
- Save and Quit to Title → Quit Game, новый процесс → тот же мир: четыре OFF сохранены в меню и HUD.
- Tab с поиска переводит фокус на общую видимость; Space выключает master без изменения модулей.
- Файл временно заменён непустым тестовым каталогом: нажатие FPS оставляет OFF и показывает ошибку. После восстановления исходного файла повторное нажатие сохраняет ON и очищает ошибку. Тестовое препятствие убрано.
- Старт и повторный вход в мир без новой ошибки Mixin. Прежняя ошибка отсутствующего Twitch SDK остаётся известным ограничением 1.8.9.

На момент первоначального среза оставались левый Shift+Tab, полный круг клавиатурного обхода, удержание клавиш при переходах, повреждённый файл при настоящем старте и геометрия меню при разных GUI scale и 720p/1080p. Эти проверки завершены в дополнении ниже; unit-тесты не выдаются за ручную приёмку.

После этого среза пользователь выбрал правый Shift вместо F9, затем попросил закрытие тем же shortcut. Открытие/закрытие и удержание 5 секунд физически подтверждены в новом dev-процессе. Двойной dispatch в mapped bytecode 1.8.9 build 604 учтён через KeyPressGate; его четыре теста проверяют дубликат открытия/закрытия, repeat, release при том же timestamp и восстановление после пропущенного release. Сборка проходит, теперь **23 Java-теста**. F8, его удержание и переходы через паузу/меню тоже подтверждены пользователем. Матрица отрисовки самого HUD SC-02 при 720p/1080p и Auto/Normal пройдена отдельно — см. SMOKE-TEST.md. CI предшествующих срезов `5ba49aa` / `d215fe1`: все четыре jobs success.

## Продолжение приёмки после SC-26

В отдельном launcher-инстансе повреждённый `schemaVersion=1 / enabled=invalid` при настоящем старте сохранён в уникальный `.bak` побайтно (SHA-256 в [QA JSON](qa/hud-acceptance-2026-10-24.json)). Игра открыла мир с defaults, меню показало `Invalid config backed up. Defaults restored.`; последующее переключение записало валидную схему 1. Это дополняет прежние проверки сохранения, перезапуска и отказа записи.

Прямой полный круг Tab проверен в игре с видимым янтарным фокусом: поиск → master → FPS → Coordinates → Keystrokes → CPS → Done → поиск. Обратный круг физическим левым Shift+Tab подтверждён пользователем. Пользователь также подтвердил удержание Space/Enter и закрытие/повторное открытие экрана с удерживаемыми клавишами: повторных переключений нет. Автоматический Shift+Tab инструментом не засчитывался: он отправлял обычный Tab из-за времени отпускания модификатора.

1920×1080 fullscreen / Auto 4 (480×270 GUI units): все карточки, поиск, статус восстановления и Done помещаются без перекрытий. Размер подтверждён IHDR родного [F2 PNG](qa/hud-menu-1080-auto-2026-10-24.png); устаревавшее после F11 превью Computer Use не заменяет родной снимок.

## Полная матрица и вход мышью

В паузу добавлена кнопка Space HUD. Она открывает прежний экран, Done/Esc возвращают в мир. Правая Shift и её KeyPressGate не менялись. Адаптер `GameMenuMixin` сверён с mapped bytecode 1.8.9 build 604; кнопка использует свободную строку vanilla, обработчик сравнивает сам экземпляр кнопки. Новая конфигурация содержит ровно ClientMixin/HudMixin/GameMenuMixin; упаковщик требует все три класса и отклоняет отсутствие, повтор и лишний Mixin.

Сборка `d5a90f18a52c2cf812dbc70feae33d31846e8d6f`, game tree `8929fc5b23b1a22a50173b96f5794175998b1a1c`: 23 Java-теста, 107 launcher tests, TypeScript и bundle build прошли. [Verify 40055469233](https://github.com/AdilSatuv/spaceclient/actions/runs/40055469233): все четыре jobs success. В отдельной QA-копии через main подготовлены 768 файлов, установлен новый собственный JAR, игра запущена дважды без ошибок Mixin. Кнопка паузы и переход к модулям проверены мышью при Normal 2 и Auto 3; Done возвращает в мир, повторный вход работает.
