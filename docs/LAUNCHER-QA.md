# Проверка Space Launcher — 23.10.2026

Windows, исходная сборка Electron 45, окно 1180×760, изолированный `SPACE_LAUNCHER_DATA=.reports/launcher-desktop`. Ранее осмотр был остановлен Esc; пользователь явно разрешил возобновить управление окном. Перед проверкой каркаса приложение перезапущено с актуальными bundles, чтобы не тестировать старый процесс.

## Каркас и профили — проверено через окно

Этот раздел фиксирует прежнюю оболочку до редизайна. Актуальный shadcn-интерфейс проверен отдельно ниже; прежняя native приёмка не выдаётся за повторную проверку нового оформления.

- Обзор, профили и настройки отображаются в палитре Nebula с оригинальной панорамой Space; при данном размере нет обрезанных блоков. После добавления прогресса страница имеет вертикальную прокрутку.
- Первый профиль переименован в «Орбита Alpha», RAM изменена с 2048 на 3072 МБ и сохранена кнопкой. Повторный клик активной карточки не сбросил несохранённый черновик.
- Через UI создан второй профиль «Орбита 2»: у него остались 2048 МБ и невыбранная Java. Переключение не изменило первый профиль.
- Native picker выбрал локальный `.tools/jdk-21/bin/java.exe` только для Alpha. Кнопка проверки вернула «Java 21 · 64 бита. Проверка пройдена». Реальная диагностика процесса прошла, не только parser fixture.
- Приложение закрыто и запущено заново. Восстановились выбранная «Орбита 2», оба имени и RAM. При переключении на Alpha сохранился путь Java, у второго профиля он остался пустым. Результат проверки Java намеренно не сохраняется между сеансами.
- Tab из поля имени перевёл видимый cyan focus на RAM; Right изменил 3072 → 3328 МБ. «Отменить» вернул 3072 и сообщение об отмене.

## Подготовка файлов — проверено через окно

Реальная загрузка, отмена на 88/758 (33,8 МиБ), продолжение и 758/758 (138,4 МиБ). После отмены receipt отсутствовал. У тестового ресурса на 73 байта изменён первый байт; hash перестал проходить, UI «Проверить и восстановить» исправил его. После добавления Log4j override приложение перезапущено, UI-подготовка завершилась на 760/760 (140,6 МиБ); полный аудит hashes снова прошёл, включая SHA-256 обоих logging jar и 14 DLL относительно локального receipt. Точные отчёты и ограничения — в [INSTALLER.md](INSTALLER.md).

## Границы результата

Повторная UI-подготовка с native cache сохранила ту же генерацию DLL: 7 папок до и после, `nativeCacheReused=true`, 29 202 000 байт повторно не скопированы. Индекс/файлы проверены до reuse, полный install audit снова прошёл. [Дисковое подтверждение](qa/launcher-native-cache-2026-10-23.json).

В сборке с собственным JAR UI показал «Space 0.1.0 · сборка для разработки», 768/768 файлов и 146,3 МиБ. Аудит сверил установленный `mods/space-client.jar` с bundle по SHA-256/source tree/metadata; 16 DLL также проверены. [Game bundle](GAME-BUNDLE.md). Публичный release и live launch этим не подтверждены.

После добавления loader manifest через окно подготовлены 767/767 файлов (146,2 МиБ) и 16 DLL. SHA-1 всего набора и SHA-256 всех 13 controlled artifacts проверены повторным аудитом. Это не запуск установленной игры; класс loader проверялся отдельно без инициализации. Подробнее — [LOADER-MANIFEST.md](LOADER-MANIFEST.md).

После добавления прогресса выявлена прокрутка всего документа вместе с titlebar/sidebar. Исправлено: фиксированная высота shell и отдельная прокрутка main. В живом окне прокрутка до footer оставляет верхнюю полосу, навигацию и локальный профиль на месте; все controls карточки доступны. [Снимок после проверки](qa/launcher-installation.jpg).

Модельные проверки sender/frame/URL, CSP allowlist, путей, ошибок/резервирования settings проходят отдельно. Описанные действия не являются независимым security-аудитом. Живые атаки навигации/subframe, runtime timeout/переполнение вывода Java, весь маршрут только клавиатурой, 200% zoom, минимальный размер 1000×680 и reduced-motion ещё не подтверждены. Открытие папки через shell также не принималось через UI. Полная установка Space, Microsoft-вход и авторизованный игровой запуск остаются незавершёнными.

Детерминированные проверки downloader/resolver/ZIP/lifecycle перечислены в [INSTALLER.md](INSTALLER.md). Игровые файлы и локальные профили не включаются в Git.

## Редизайн shadcn/ui — renderer-проверка

Новая оболочка: графит, голубой акцент, локальные Button/Card/Input/Badge и Lucide. Проверка отдельного Electron с disposable data подтвердила три раздела на четырёх viewport (1180×760, 1000×680, 600×680, 500×380), отсутствие горизонтального overflow, keyboard RAM/cancel/dirty guard, сохранение/выбор двух профилей, перенос длинного имени, focus нижнего control при прокрутке и prefers-reduced-motion. Native picker, живые downloads/cancel в новом оформлении, OS zoom 200% и screen reader повторно не проверены. Узкий viewport не заменяет системное масштабирование.

Из renderer недоступны Node globals, bridge содержит прежние десять функций; skip-control не изменяет точный IPC URL. Inline style attributes и renderer/CSP errors в прогоне отсутствуют. Проверенные текстовые пары contrast ≥8,05:1, CTA 10,61:1, input boundary 3,27:1. Это выборочная проверка пар, не WCAG certification.
