# Ping, Biome, Pack Display и Keystrokes · 2 ноября 2026

По запросу пользователя добавлена следующая партия собственных модулей Space. Код или ресурсы сторонних клиентов не использовались.

- **Ping** читает последнее значение latency локального игрока из server player list. В одиночной игре показывает `Ping: Singleplayer`, при отсутствии записи/мира — `Ping: --`. Отдельные сетевые пробы не отправляются; это серверное значение, а не независимый benchmark RTT.
- **Biome** показывает имя биома в загруженном столбце текущих X/Z. Проверка загрузки использует допустимую высоту, поэтому полёт выше/ниже build height не скрывает доступный биом. Не создаёт и не загружает новые чанки; без данных показывает `Biome: --`.
- **Pack Display** перечисляет выбранные ресурспаки, отмечает присутствие server pack словом `Server`. Без выбранных паков показывает `Pack: Default`; при недоступном loader — `Pack: --`. Отображение ограничено первыми двумя именами и количеством остальных, имена очищаются от управляющих/форматирующих символов и ограничены по codepoints. Виджет показывает выбранный loader список, не проверяет успешность применения каждого стороннего пака.
- Новые три HUD-виджета выключены по умолчанию, доступны через Home/HUD и соответствующие категории. Их стандартная привязка — справа сверху, с отдельными строками. Оба профиля, редактор, масштаб и внешний вид сохраняют прежнее поведение.
- **Keystrokes** теперь включает прыжок и attack/use bindings. Надписи соответствуют фактическим назначениям; мышь обозначается M1/M2 и т. д., переназначение действия на клавиатуру также отражается. В Content можно отдельно скрыть прыжок и attack/use. Для каждой подписи резервируется ширина обоих состояний, поэтому нажатая клавиша не сдвигает следующие. Редактор и anchor/nudge используют тот же размер.
- Подсветка Keystrokes выключается вне активной игры, при меню или потере фокуса. Управляющие и bidi-format символы в подписях отфильтрованы. Compass корректно показывает недоступность без игрока.

HUD schema 11 и экспорт v6 сохраняют поддержку схем 1–10/экспортов v1–v5. До изменения прежних HUD-файлов создаётся проверенная резервная копия. Новые параметры Keystrokes по умолчанию включены; настройки цветов/размещений, старые флаги и содержимое других модулей сохраняются. В тесты добавлены реальные fixtures сериализатора `170f32c`, созданные из предыдущего проверенного JAR, и проверки переключения/независимости параметров.

Прошли 144 Java-теста, все 112 тестов лаунчера, TypeScript, сборка и строгая проверка source stamp. [Метаданные и хеши](qa/context-modules-2026-11-02.json).

В отдельном QA-инстансе создан собственный плоский мир `Space Context QA` (seed 12345) и пустой локальный ресурспак `Space QA Pack`. Настоящий Minecraft подтвердил `Ping: Singleplayer`, `Biome: Plains` и `Pack: Space QA Pack`; получен framebuffer-снимок HUD с реальным миром. Открыт Content Keystrokes, оба новых параметра выключены/включены реальными методами экрана, после чего снят экран настроек. Оба снимка осмотрены: надписи и новые настройки видны, переполнения не обнаружено. Процесс завершён с кодом 0.

QA работал в невидимом AWT Canvas; отдельный временный addon запрещал захват мыши/фокуса. Пользовательские миры не открывались, Desktop/OS input не вводился. Исходники и addon находятся в игнорируемой `.reports`, в обычный Space JAR не входят. QA ограничен 60 FPS: снимок не является измерением производительности. Multiplayer latency на живом сервере и физические переходы клавиатуры/мыши не проверены.
