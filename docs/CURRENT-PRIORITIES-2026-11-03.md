# Что важно после обновления меню · 3 ноября 2026

Аудит выполнен по текущим исходникам и локальным QA, без новых облачных сервисов, публикации и удалённых изменений. Регистрация Space, общий профиль, изменение внешности, rollback игрового JAR, backup настроек и новые меню уже реализованы; повторять их как незакрытые задачи не нужно.

## 1. Производительность HUD

Предыдущая короткая серия на tree22056fa56090 показала median loop763 FPS для Fabric control,756 для Space HUD off,668 для пяти стандартных HUD и 437 при всех 26. Это instrumented hidden loop с glFinish, а не displayed FPS или доказательство текущей регрессии. Новая тема меняет меню; новый игровой performance benchmark здесь не запускался. [Условия и сырые samples](qa/native-hud-observations-2026-11-03.json).

Следующий полезный срез: профилировать CPU/render/allocations в обычной игровой сессии, начать с повторных вычислений текста/ширины/инвентаря и переключений GL state. `HudRenderer.render` получает текст и bounds каждого включённого модуля каждый кадр; `InventoryHud.text/draw` повторно сканируют инвентарь. Это кандидаты для измерения, не доказанные единственные причины затрат. Отдельно измерить заполненный инвентарь, броню/эффекты, blur/particles и косметику. Приёмка: одинаковый маршрут, прогрев, несколько повторов, P95/P99/1% low и отсутствие ухудшения отзывчивости; затем понятные presets. Кеширование должно учитывать реальные события/тики, а не задерживать клавиши и боевые наблюдения.

## 2. Полный путь установки и обновления приложения

Native setup уже проверяет payload, длинные пути, отмену и сохранность прежней цели. Это не полный packaged-entry lifecycle на чистой Windows. `installer/Setup.cs` прямо отказывает при существующей папке/ярлыке; JAR/receipt rollback не является обновлением самого Electron-приложения. Штатного деинсталлятора нет.

Нужно: приёмка новой Windows VM без dev JDK/cache, установка→Java/download→запуск мира→повторный запуск; затем app upgrade/repair/uninstall с сохранением данных. Проверить недостаток места и прерывание после каждого этапа. Критерий: сценарий работает из установленного приложения и не зависит от `.reports`. Подпись/публичный release — отдельный последующий этап.

## 3. Жизненный цикл Space-аккаунта

Текущий controller поддерживает register/login/logout/me/nickname/skin/cape/assets. Нет смены/восстановления пароля, списка устройств и выхода из всех сессий, удаления аккаунта. Сессии уже ограничены сроком и количеством; токены хранятся хешами, неиспользуемые assets уже удаляются транзакцией. Эти существующие защиты не нужно описывать как отсутствующие.

Для следующего среза: смена пароля с проверкой текущего и отзывом других сессий; понятные активные устройства/«Выйти везде»; выбранный владельцем способ восстановления доступа; backup/restore SQLite с доказательством восстановления аккаунта и PNG. Не вводить email-восстановление без решения о подтверждаемом адресе. До публичного сервиса также нужна эксплуатационная приёмка HTTPS/storage/monitoring/backup. Сейчас launcher default endpoint localhost3001, локальный просмотр отдельно привязан к 50565/50566; установленное приложение не превращается в публичный сервис автоматически.

## 4. Полная игровая матрица

Hidden native handler/TCP проверки уже есть. Следующий уровень: hold/release/rebind/focus, Alt+Tab, F1/F3, смерть/respawn/dimension/переподключение, ресурспаки/shaders и длительная совместная работа всех 55 модулей на контролируемом сервере. Физическую проверку пользователь ранее отложил; повторного запроса в этой задаче не было. Критерий: поддержанные сценарии и остаточные ограничения записаны для каждого модуля, а не общий «всё работает».

## 5. Упростить навигацию и завершить русский текст

В паузе `Space HUD` открывает каталог 55 модулей, а `Space Mods` всё ещё ведёт в старый экран только ToggleSprint/FreeLook. Он теперь оформлен общей темой, но дублирует часть каталога. Следует оставить один понятный каталог с нужными фильтрами и прямой ссылкой в редактор. RU оболочка и основные пояснения работают; отдельные названия/описания и legacy-экран остаются английскими. Критерий: один маршрут к каждому действию и полный осмотр compact RU без сокращений, скрывающих смысл.

## Отдельно от текущего поручения

Microsoft/Xbox/Minecraft официальный вход и публичный hosting ранее отложены пользователем. Их не запускали автоматически. Косметика и внешность по действующему контракту локальны; видимость другим игрокам требует отдельного сетевого дизайна и серверной проверки. Remote CI точного локального snapshot не запускался при режиме без push; локальный workflow существует. Первопричина старого единственного API worker exit неизвестна, диагностические hooks добавлены. Свежая Codebase Memory недоступна (`Transport closed`); выводы выше сверены по файлам, не по устаревшему графу.

Порядок практической работы: измерить/снизить затраты HUD → принять установленное приложение на чистой Windows → завершить жизненный цикл аккаунта. Новые функциональные работы этим документом не начаты.
