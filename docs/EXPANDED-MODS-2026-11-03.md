# Ещё 11 модулей · 3 ноября 2026

По запросу «все из списка» добавлены 8 игровых модулей и 3 HUD-виджета. Теперь 29 игровых + 26 HUD = **55 карточек**. Все новые модули по умолчанию выключены, Toggle key не назначены. Открытие: правый Shift → поиск названия; три счётчика перемещаются и оформляются в существующем редакторе HUD.

| Модуль | Реализованное поведение и настройки |
|---|---|
| Combo Counter | Последовательные client-observed попадания: собственная атака + hurt status той же цели в пределах 1 секунды; дубликат не считается. Смена цели, собственный hurt и пауза 2 секунды сбрасывают серию. Чужой удар по недавно атакованной цели также может дать status: это не серверное подтверждение авторства попадания. |
| Reach Display | Дистанция от глаз до native crosshair hit vector последней атаки, до двух знаков; через 5 секунд `--`. Только измерение по данным клиента. |
| Scoreboard | Оформляет уже существующий sidebar objective: числа on/off, фон, масштаб 50–150%, X/Y offsets −500…500. Native сортировка, команды и последние 15 видимых строк сохранены; серверные данные не меняются. Defaults: числа off, фон on, масштаб 100%, offsets 0. |
| TNT Countdown | Надпись над видимым native TNT, цвет, фон, дальность 8–128. Default Gold/фон on/64. Остаток native fuse в секундах, с учётом tick delta; серверный нестандартный fuse может отличаться. Depth test сохраняется. |
| Saturation | Отдельный HUD с текущим client saturation; на сервере пометка `~`, поскольку 1.8.9 не синхронизирует точное значение. В native tooltip еды добавляются номинальные Food/Saturation gains до ограничений текущего голода и насыщения. |
| Scrollable Tooltips | Прокрутка длинных native текстовых подсказок, не помещающихся в экран; Shift+wheel по горизонтали, скорость 2–30 пикселей, default 10. Scissor удерживает текст в окне, смещения ограничены размером содержимого и сбрасываются при смене текста/экрана. |
| Waypoints | Локальные именованные метки: Add here, имя 1–32 символа, X/Y/Z, цвет, видимость, удаление и страницы. Manage markers открывает отдельный экран. Изоляция по хешу идентичности мира/сервера и dimension. Луч и расстояние on/off, оба default on. Depth-tested world labels до 8192 блоков; подписи близких точек опущены ближе к точке. Без телепортации, обмена и пересчёта Nether coordinates. |
| Particles | Количество 0–300%, размер 50–200%, опциональный tint и палитра. Defaults 100%/100%/tint off/Aqua. Factory particles размножаются до 3× с native limits; прямые block-debris instances только прореживаются/масштабируются/окрашиваются, не клонируются. |
| Enchantment Glint | Цвет, скорость 25–300%, сила 10–100% для native item и armor glint; defaults Violet/100%/100%. Меняется tint/движение существующего блеска, текстуры resource pack сохраняются. |
| Inventory Blur | Собственный separable Gaussian shader GLSL 1.20: нормализованное ядро 17 taps, линейные промежуточные текстуры, сила 1–8, default 4. Размывает фон за HandledScreen, оставляя инвентарь чётким. Не заменяет native активный shader; нужны OpenGL 2.0 и framebuffer, иначе остаётся обычный фон. |
| Dynamic FPS | Background cap 5–60 FPS, idle cap 10–120 FPS после 10–300 секунд. Defaults 30/60/60. Движение мыши, события клавиш/кнопок и удерживаемые native controls считаются активностью. Более низкий Minecraft cap имеет приоритет, saved maxFramerate не меняется. |

## Сохранение и сборка

Mods schema10 / 132 поля с чтением схем 1–9; HUD18 с чтением 1–17, export13 с чтением 1–12, browser1 прежний. Три настоящих fixture предыдущего сериализатора получены до изменения исходников: mods9, HUD17 и export12 от `1af3562`. Старые включения/клавиши/профили/appearance/placements сохраняются, новые opt-in. Открытие старых файлов не записывает их; старый HUD получает существующую verified backup миграцию перед обновлением. Writes атомарные, ошибки откатываются, future/unreadable mod settings остаются read-only.

Метки сохраняются отдельно в `config/spaceclient-waypoints.properties`, schema1, максимум 262144 байта, 64 точки на context+dimension и 512 всего. Некорректные/будущие данные остаются read-only с сохранением оригинала, failed write не меняет список. Идентичность мира/сервера хранится как SHA-256, данные миров не редактируются. User marker config также входит в контроль сохранности при установке.

Лаунчер требует точные **35 production mixins**, новые classes и Java8 major52. Bundle limits, source stamp и native assets не ослаблялись. Исходные commits: `1479935`, `4213be2`, `2a297a3`, `de9ec98`; QA helpers не входят в обычный JAR.

## Проверено

Прошли **249 Java + 112 launcher tests**, TypeScript, Prettier, game build и строгая launcher bundle build. Проверены реальные migrations/round trips, независимый reset, rollback, malformed/future preservation, waypoint isolation/removal/persistence, combo status/timeout/debounce, idle cap/native priority/activity, tooltip offset bounds и сохранение равномерного цвета Gaussian kernel.

Native QA: скрытый Canvas 1280×720, отдельный QA-профиль и QA-мир, exitCode=0. Все 15 финальных captures осмотрены. Проверены search/cards, восемь экранов settings, настоящие mouse handlers и key capture/unbind, три HUD-виджета, synthetic native hurt status и crosshair vector, factory multiplier 3×/zero, particle size/tint, marker add/name/color/hide; повторное чтение marker-файла проверено unit tests. Отдельно требуются свежие native вызовы **и TNT, и Waypoints** после setup; это не один общий счётчик. Кадры показывают labels/tablo/HUD, manager, длинную/прокрученную подсказку, native food tooltip Apple +4/+2.4, item/armor Lime glint, обычный и размытый фон. Creative inventory перенаправлял проверку с экрана модели игрока; использован локальный survival sample и обновление только клиентских предметов перед кадром, прежний game mode восстановлен.
