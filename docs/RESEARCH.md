# Исследование: Lunar Client, Badlion Client, ViperClient

Дата: 23 октября 2026. Метод: изучение публичных официальных страниц и документации. Бинарные файлы конкурентов не запускались, производительность и поведение внутри игры не проверялись. Заявления производителей об FPS не являются результатами наших измерений. Наборы функций могут меняться; точные версии и зависимости проверять перед каждым релизом.

## 1. Lunar Client

[Features](https://www.lunarclient.com/features), [начало работы](https://www.lunarclient.com/news/getting-started-with-lunar-client), [профили](https://support.lunarclient.com/solutions/how-to-create-a-lunar-client-profile), [FAQ](https://www.lunarclient.com/faq).

Позиционирование: готовая среда Minecraft с интегрированными модами, настройками и лаунчером. Страница Features указывает 65+ модификаций; другие страницы могут давать другое количество, поэтому число не используем как стабильную спецификацию. Примеры: Keystrokes, Coordinates, Toggle Sprint. Заявлены Windows, macOS, Linux и поддержка нескольких поколений игры. Оптимизация — центральный аргумент продукта, но обещание кратного прироста FPS требует независимого тестирования.

Пользовательский путь: установка → выбор/создание профиля → версия и загрузчик → вход → запуск → настройка модов, клавиш и HUD. Мастер профиля позволяет задать название, описание, версию, загрузчик и изображения, также есть импорт. FAQ различает возможности добавления пользовательских модов на старых версиях и Fabric на новых: нельзя считать поддержку модов одинаковой на всех версиях.

Вывод для Space: профиль должен объединять версию, runtime и настройки модов, но профиль запуска и расположение HUD — разные сущности. Не пытаться в первом релизе повторить мультиверсионность Lunar.

## 2. Badlion Client

[About](https://www.badlion.net/about?lang=en), [FAQ](https://www.badlion.net/wiki/faq).

Позиционирование: комплексный клиент с набором модов и автоматическим обновлением. В About перечислены ArmorStatus, PotionStatus, Keystrokes, Crosshair, CPS/FPS/Ping counters и другие модули. Описан запуск в singleplayer, Realms и на совместимых серверах. Это не доказывает допустимость каждого модуля по правилам конкретного сервера.

FAQ отдельно указывает редактирование GUI и Mod Profiles. Следовательно, удобство настройки в самой игре — самостоятельная часть продукта, а не просто экран параметров лаунчера.

Вывод для Space: каталог модулей с поиском, включением и настройками; редактор HUD с перемещением, масштабом и сбросом; профили HUD. FPS и CPS — хорошие первые модули, поскольку их можно проверить без сложного игрового поведения.

## 3. ViperClient

[Официальный сайт](https://viperclient.com/). Под Viper понимается именно этот продукт; одноимённые проекты не объединяем.

По индексируемой версии официального сайта: фокус на Minecraft 1.8.9 PvP, Windows 10/11 x64, HUD/ClickGUI, визуальных настройках и оптимизации. Указаны bundled Java 21 и автоматические обновления лаунчера, упомянуты entity culling и ограничение частиц. Бесплатная основа дополняется необязательной косметикой. Сайт описывает Microsoft/offline вход.

Ограничение: при прямом чтении сайт не отдал извлекаемый текст; сведения получены из поискового индекса его официальной страницы. Детали виджетов, реализации runtime и точный список модулей не подтверждены запуском. Надпись Java 21 у конкурента не доказывает совместимость обычной Forge-сборки 1.8.9 с Java 21. Offline-вход не переносим в Space как способ доступа к лицензированным сервисам.

Вывод для Space: узкий старт с 1.8.9 реалистичнее широкой поддержки версий. Заимствуем принцип компактного продукта, не код и не внешний вид один в один.

## 4. Сравнение и решения

| Область | Наблюдение | Решение Space |
|---|---|---|
| Версии | Lunar/Badlion охватывают несколько; Viper делает упор на 1.8.9 | Сначала 1.8.9, новые версии отдельными адаптерами |
| Настройки | Профили, моды, HUD — общая продуктовая потребность | Версионированные схемы, раздельные launch/HUD профили |
| Быстродействие | Маркетинговые обещания не сопоставимы | Собственный воспроизводимый benchmark |
| Сайт | Загрузка и объяснение продукта | Возможности, загрузки, changelog, помощь |
| Экосистема | Косметика и дополнительные сервисы расширяют продукт | Вынести за пределы MVP |
| Обновления | Лаунчер должен обслуживать установку | Верификация файлов, восстановление, затем updater |

## 5. Технические источники и неопределённости

- [Forge 1.8.9 downloads](https://files.minecraftforge.net/net/minecraftforge/forge/index_1.8.9.html): есть официальная ветка 1.8.9. До выбора собрать минимальный MDK на чистой машине и проверить совместимые JDK/Gradle. Старую цепочку не считать совместимой с современными JDK автоматически.
- [Legacy Fabric](https://legacyfabric.net/): отдельный проект поддержки старых Minecraft. Кандидат для сравнительного эксперимента, не обычный современный Fabric.
- [Fabric develop](https://fabricmc.net/develop/): зависимости зависят от целевой версии. Современный Fabric не принимается как готовый путь для 1.8.9.
- [Electron security](https://www.electronjs.org/docs/latest/tutorial/security/): для возможного лаунчера нужны sandbox, изоляция контекста, узкий IPC и запрет произвольного Node.js в интерфейсе.
- [Microsoft OAuth](https://learn.microsoft.com/en-us/entra/identity-platform/v2-oauth2-auth-code-flow): для desktop-входа исследовать системный браузер и PKCE. Microsoft OAuth сам по себе ещё не завершает Xbox/XSTS/Minecraft-авторизацию и проверку владения; доступ приложения к игровым API — отдельный риск и задача.

Неизвестно: внутреннее устройство закрытых клиентов; фактическая производительность; полный список Viper-модулей; доступность Microsoft/Minecraft-интеграции для нашего приложения. Эти пункты нельзя выдавать за изученные по исходникам или проверенные в игре.
