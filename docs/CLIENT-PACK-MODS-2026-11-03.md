# Animations, Auto Text, GUI и оформление предметов · 3 ноября 2026

Добавлены семь opt-in игровых модулей и улучшен существующий Item Counter: 21 игровой + 23 HUD = 44 карточки. Открытие: правый Shift → поиск названия. Новые модули выключены, Toggle key и клавиши макросов не назначены, тексты макросов пусты. Настройки, векторные предпросмотры, избранное и плавные переключатели используют общий каталог. Пользователь уточнил, что **GUI означает масштаб игрового интерфейса**.

- **Animations**: отдельные переключатели block hit, eating и bow, все включены внутри выключенного родительского модуля. Визуальный взмах при блокировании мечом, смещение/поворот еды и лука от первого лица. Это три legacy-style эффекта, не полный набор исторических анимаций 1.7. Косметический взмах не вызывает атаку и не отправляет пакеты.
- **Auto Text**: три слота, собственные текст и клавиша каждого; до 100 UTF-16 символов, одна строка. Enter сохраняет, Esc отменяет, Backspace удаляет кодовую точку, Ctrl+V вставляет допустимый текст. Контрольные/форматирующие символы, § и некорректные surrogate-пары отклоняются. Общая пауза 1 секунда, защита от повторов события, конфликтов native/hold/toggle/macro keys; только живой игрок в сфокусированной игре без открытого экрана. Смена игрока/мира сбрасывает gate, ссылки на игрока слабые.
- **GUI**: Auto или 1–4, по умолчанию 2 внутри выключенного модуля. Сохраняет native ограничение 320×240 и Unicode-логику. Предел зависит от разрешения; подсказка показывает фактический масштаб. Экран и framebuffer обновляются при смене эффективного масштаба без изменения размера окна ОС; `options.guiScale` и options.txt не переписываются.
- **Hitboxes**: фильтры Players/Mobs/Items, палитра с Rainbow, линия 1–3. По умолчанию Players+Mobs, Items off, Aqua, ширина 1. Native bounding boxes видимых сущностей; скрытые/удалённые и собственный игрок от первого лица исключены, F1 скрывает линии. Depth test сохраняется, GL state восстанавливается. Физические размеры сущностей не меняются.
- **Item Counter**: улучшена существующая HUD-карточка без дубликата. Native иконка выбранного предмета, общее количество и число занятых совпадающих стаков; совпадение по item/damage/NBT в основном инвентаре и хотбаре. Например, три стака жемчуга 16+8+4 показывают 28 / 3 stacks.
- **Item Physics**: лежащие плоские предметы без native bob, стабильный поворот на земле; вращение в воздухе со скоростью 1–5, default 2, Flat on ground default on. Использует native render matrices; гравитация, подбор и столкновения не меняются.
- **Item Size**: отдельный масштаб руки 50–150% и выпавших предметов 25–200%, defaults 80%/100%. Работает совместно с Item Physics, учитывает высоту native модели. Карты и инвентарные иконки сохраняют native размер.
- **Sounds**: независимые Vanilla/Soft/Crisp/Arcade для блоков/шагов и боевого hurt, громкость; default Crisp/Soft/70%. Target down: Off/Orb/Pling/Levelup, default Orb, плюс локальный Preview. Сигнал возникает однократно по native death status той же цели, которую игрок атаковал не более 3 секунд назад; это не подтверждённый сервером зачёт убийства. Серверы с destroy-only/custom протоколом могут не подавать сигнал. Используются существующие Minecraft sound events; категории, identity sound instance, looping/tickable sounds, музыка и чужие namespaces сохраняются. Импорт аудиофайлов не добавлен.

## Проверка и установка

Прошли **239 Java + 112 launcher tests**, TypeScript, Prettier, game build и строгая launcher bundle build. Native QA выполнен в скрытом Canvas 1280×720, отдельном QA-профиле и QA-мире, exitCode=0. Все 17 финальных снимков осмотрены. Проверены карточки/настройки/предпросмотры; редактор макросов, сохранение/отмена, key capture/conflicts и cooldown; GUI live 1×/2× и native caps запросов 0–4; неизменность Minecraft GUI option; фильтры хитбоксов, depth/GL state; Counter с native иконкой 28 / 3 stacks и GL/cache restore.

Native held renderer проверен на block swing и eat/bow matrices; native dropped renderer — на землю/воздух/размер. Кадры показывают размер руки 100%/60%, native и лежащий меч, контуры сущностей. Проверены native sound registry/category remap, volume/pitch и looping guards. Синтетический death status обработан настоящим клиентским packet handler; отслеживаемая цель даёт один сигнал, дубликат подавлен. Все macro send и preview/chime output перехвачены QA, реальные сообщения не отправлялись. Остальные sound pipeline samples выполнялись при нулевой громкости; звук на слух не проверялся.

Первый QA-образец block-use сбрасывался native tick до рендера: исправлен момент подачи только QA input. Позднее осмотр кадров обнаружил отсутствие мировых хитбоксов при успешном isolated GL probe. Production hook перенесён с публичного dispatcher overload на реально используемый `method_6913`; QA теперь требует новые world draw observations после probe. Полный финальный повтор и кадры подтвердили исправление. Завершался только собственный аварийный QA Java, пользовательскую игру не останавливали.

Physical input, clipboard paste, реальная доставка Auto Text на сервер, сетевые игроки/полная occlusion матрица хитбоксов, Unicode/high-DPI матрица GUI, multiplayer, shader/resource-pack matrix и performance не приняты. Пользовательские миры не открывались. Native samples и нулевая громкость не заменяют эти проверки.
