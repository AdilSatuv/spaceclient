# Локальный Windows setup лаунчера

Это локальный **development**-установщик Windows x64, не подписанный публичный релиз. Он включает Electron, лаунчер и проверенный собственный development JAR Space. Файлы Minecraft и Java не входят; их подготовка остаётся отдельным действием в лаунчере. Локальный ник не является онлайн-аккаунтом, а успешная установка приложения не подтверждает готовность игры.

Setup устанавливает приложение только для текущего пользователя в `%LOCALAPPDATA%\Programs\Space Client` и создаёт ярлык «Space Client» в меню «Пуск». Если целевая папка или ярлык уже существуют, setup отказывается их заменять. Он не меняет данные профилей или миры. При ошибке он сообщает о временных файлах либо о частично размещённом приложении; перед повтором нужно проверить указанные пути. Автоматического обновления и деинсталлятора пока нет. Для ручного удаления после закрытия лаунчера можно удалить его папку и ярлык; пользовательские данные хранятся отдельно и таким способом не удаляются.

## Сборка и проверки

Требуются Windows x64, Node/npm, существующий Electron из закреплённого lockfile, .NET Framework с `csc.exe` и валидный `game/build/libs/space-client-0.1.0.jar`. В чистом game tree сборщик требует `SPACE_REQUIRE_GAME_BUNDLE=1` и проверяет source stamp штатным bundler. Из корня:

```powershell
node apps/launcher/scripts/package-setup.mjs
node apps/launcher/scripts/test-setup.mjs <выведенный-каталог-сборки>
```

Сборка остаётся в игнорируемом `.reports/launcher-setup`; bundled dependencies и их лицензии отбираются по графу esbuild, лицензии Electron/Chromium включены. Для конкретного локального файла 27 октября 2026 размер 161 652 224 байта, SHA-256 `c1c6e9de3265d5bdd46249b5683ec137c40397ad625488891a54461976badb16`; собственный JAR имеет tree `ad06bc5f13ca76788f6c0832e9f72e77843219ac` и SHA-256 `11299c35e8812de73373f75c0a3cef721f40308bb7f510fa7387c4f70c376257`. Хеш конкретного файла может отличаться при другой сборке и не является подписью издателя.

Без окон тестовый исполняемый файл распаковал 98 файлов в изолированный каталог; все размеры и SHA-256 совпали с payload. Существующая папка сохранена, опасные и повторные пути отклонены до записи. Встроенный ZIP совпадает с проверенным payload; все семь размеров иконки в setup и копии Electron сверены с исходным ICO. Реальная установка, COM-ярлык, запуск установленного приложения, деинсталляция и чистый профиль Windows не проверены. У setup нет Authenticode-подписи; Windows может показать предупреждение. Автоматизированная проверка распаковки не является полноценной приёмкой установщика. SC-14 остаётся открытой: публикация, CI артефакта, подпись, обновления, восстановление и остальные критерии релиза не выполнены.
