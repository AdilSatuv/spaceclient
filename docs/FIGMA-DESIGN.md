## Новое направление

- Midnight navy/black, ice-blue основной акцент, сдержанные violet highlights, белый текст. Мята больше не является основой нового макета.
- Игровая ночная сцена с блочными островами и светящейся орбитой заполняет hero; бренд и действие остаются читаемыми поверх неё.
- Заголовок-кандидат: «ТВОЙ МИР. НОВАЯ ОРБИТА.». Короткий абзац, «К загрузкам» и вторичное «Возможности».
- Чёткая метка: «В разработке · Minecraft 1.8.9 · Windows x64». Без несуществующего установщика.
- Не строить страницу из одинаковых карточек; чередовать игровой hero, компактную полосу, большую HUD-демонстрацию, шаги, заметку и FAQ.
- Все будущие игровые UI-демонстрации помечены «Концепт». Не выдавать иллюстрации за снятые в игре скриншоты.

## Заказанный состав Figma-макета

1. Главная desktop 1440 px: навигация, hero, capability strip, HUD-демонстрация, три шага, заметка от 23.10.2026, FAQ, footer.
2. Главная mobile 390 px: отдельная компоновка, а не уменьшенный desktop.
3. Features: фильтры, статусы прототип/план, результаты и пустое состояние.
4. Downloads: совместимость и отсутствие публичной сборки; реальная download-кнопка не появляется до релиза.
5. Updates: реальные заметки разработки и шаблон статьи.
6. Help: поиск, инструкции, FAQ и шаблон статьи.
7. Повторяемые кнопки, навигация, cards/HUD widgets — компоненты; semantic text styles и именованные tokens. Auto-layout для связанных элементов.

## Проверка перед переносом в код

- В файле есть реальные редактируемые Design-слои; полная UI-картинка не подменяет текст/структуру.
- Заголовки и русский текст не обрезаны, компоненты не перекрываются.
- Шрифты поддерживают кириллицу, состояния управления различимы.
- Desktop и mobile имеют самостоятельную иерархию и понятный CTA.
- Статусы соответствуют проекту: FPS/XYZ/keystrokes — dev-прототип; HUD editor и launcher — план.
- Нет фиктивных метрик, отзывов, готовых релизов или ссылок скачивания.
- Композиция проверена в самом Figma-файле; найденные проблемы исправляются точечно.

До завершения этой проверки новый вариант не считается реализованным на сайте. Локальная Next.js-вёрстка предыдущего варианта — рабочий черновик, не утверждённый результат редизайна.

## Реализованный срез 23.10.2026

В отдельном файле созданы шесть native Design-фреймов: главная desktop/mobile, возможности, загрузки, обновления, помощь. Через Layers проверена структура главной: шапка, hero с отдельными текстом/кнопками/затемнением, полоса возможностей, игровой интерфейс, шаги, заметка, FAQ, подвал. У desktop hero подтверждены 1440×800 и auto-layout; это не одна UI-картинка.

После исчерпания дневных Figma AI credits генерация остановлена. Desktop hero вручную доработан: векторная панорама сохранена скрытой, на контейнер добавлена image fill с оригинальной `space-hero-v2.png`; текст и кнопки остались редактируемыми. Mobile и внутренние Figma-фреймы пока используют первоначальную векторную панораму. Полная библиотека variables/components и все control states ещё не приняты — SC-17 остаётся открытой.

Next.js теперь содержит новый navy/ice-blue вариант главной, общие navigation/footer, HUD-концепт, FAQ, шаги и заметку. На desktop проверена композиция; на 390 px — компоновка в iframe-стенде. Это не заменяет проверки клавиатуры, меню, zoom и итоговых performance-замеров. Формальные результаты приёмки записываются отдельно, до них SC-18/SC-23 не закрываются.

Последующий срез проверен уже в прямых browser viewport 320–1440 px; подробности в WEBSITE-QA.md. Для веб-мобильной главной подготовлена самостоятельная вертикальная `apps/website/public/images/space-hero-mobile-v1.png` (940×1673); она выбирается через picture/getImageProps. Следующая правка в Figma — заменить фон mobile hero этой image fill, сохранив native текст, кнопки и затемнение. На текущем снимке файла mobile ещё содержит векторную панораму. Browser-просмотр подтверждает все шесть фреймов и сохранённый новый desktop фон; без входа он доступен только для просмотра. Настольное управление свёрнутым окном не удалось восстановить; это не отмечается как выполненная правка.
