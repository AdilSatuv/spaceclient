# Инструкции для работы над Space Client

- Прочитать README.md, docs/SPEC.md и docs/DEVELOPMENT.md перед изменением архитектуры.
- Репозиторий содержит Minecraft Java-клиент и сайт. Не выдавать интерфейс лаунчера за рабочую игру.
- Архитектура сайта Next.js + NestJS — docs/WEB-ARCHITECTURE.md. Для лаунчера выбраны собственная регистрация Space и локальный вход по нику (SC-25); регистрация — отдельный будущий срез. Microsoft-вход отложен. SC-07/09 закрыты; установка development JAR не означает готовность Space к запуску. Игровые проверки SC-02 и дополнительная UI-матрица сохраняются в трекере/QA.
- Фиксировать выбранные версии JDK, Gradle, загрузчика и mappings. Не добавлять SNAPSHOT/latest без явно описанной причины.
- Инструменты и caches хранить в игнорируемых каталогах. Не менять глобальные настройки Java и Git.
- Для Java запускать проверки через scripts/game.ps1; команды должны использовать локальный JDK.
- Игровые файлы, runtime, секреты и токены не коммитить.
- После законченного изменения выполнить подходящие проверки, git diff --check, просмотреть staged diff, сделать содержательный коммит и git push origin main.
- Автор коммитов уже настроен локально. Не менять даты и не создавать пустые коммиты ради contributions.
- В документации и сайте различать реализованное, проверенное сборкой и проверенное внутри игры.
- Функции конкурентов изучать по официальным источникам, оформление и код создавать самостоятельно.
- Делегирование агентам не требуется; выполнять работу в текущем чате.
- Брать следующую задачу из GitHub Issues с учётом зависимостей. Индекс — docs/TASKS.md; подробный порядок — docs/IMPLEMENTATION-PLAN.md.
- Последнее уточнение приоритета: SC-25/26 завершены; пользователь поручил продолжать остальные задачи. Игровая матрица SC-03 завершена, закрывать после CI; для SC-04 остаются комбинации разрешений/GUI scale. SC-05 не начинать до приёмки #3/#4. Microsoft и публикация сайта отложены. Текущее состояние — docs/CHAT-HANDOFF.md.
- При большом контексте пользователь разрешил свежий чат после крупной задачи. Завершить срез, проверки, commit/push и обновить docs/CHAT-HANDOFF.md перед передачей. Новые чаты: model gpt-6.1-sol, thinking high, раздел Space Client. Использовать Codebase Memory, когда доступен; ошибку подключения не выдавать за успешную индексацию.
- Ссылаться на задачу в коммите через Refs #N. Закрывать issue только после проверки всех критериев и записи результата, не по факту компиляции.
