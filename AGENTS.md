# Инструкции для работы над Space Client

- Прочитать README.md, docs/SPEC.md и docs/DEVELOPMENT.md перед изменением архитектуры.
- Репозиторий содержит Minecraft Java-клиент и сайт. Не выдавать интерфейс лаунчера за рабочую игру.
- Основная цель первого среза: Minecraft 1.8.9, Windows x64, настоящий HUD и воспроизводимая сборка.
- Фиксировать выбранные версии JDK, Gradle, загрузчика и mappings. Не добавлять SNAPSHOT/latest без явно описанной причины.
- Инструменты и caches хранить в игнорируемых каталогах. Не менять глобальные настройки Java и Git.
- Для Java запускать проверки через scripts/game.ps1; команды должны использовать локальный JDK.
- Игровые файлы, runtime, секреты и токены не коммитить.
- После законченного изменения выполнить подходящие проверки, git diff --check, просмотреть staged diff, сделать содержательный коммит и git push origin main.
- Автор коммитов уже настроен локально. Не менять даты и не создавать пустые коммиты ради contributions.
- В документации и сайте различать реализованное, проверенное сборкой и проверенное внутри игры.
- Функции конкурентов изучать по официальным источникам, оформление и код создавать самостоятельно.
- Делегирование агентам не требуется; выполнять работу в текущем чате.
