# Space Client

Собственный Minecraft Java PvP-клиент и сайт. Автор: AdilSatuv.

Стадия на 23 октября 2026: игровой прототип, сайт Next.js/API NestJS и desktop-лаунчер с профилями, Java, установкой/восстановлением файлов и development JAR Space. Microsoft-входа, запуска игры из лаунчера и публичного установщика пока нет.
Репозиторий: https://github.com/AdilSatuv/spaceclient

Сайт уже содержит главную, возможности с фильтрами, загрузки, журнал со статьями и помощь. Контентные разделы подключены к NestJS; отсутствие пользовательского релиза и отказ API различаются. Главная использует самостоятельные desktop/mobile иллюстрации. Figma-библиотека и полная матрица приёмки ещё в работе; публичного размещения пока нет.

Текущий приоритет — сам лаунчер. Работают локальные профили, память, выбор/диагностика Java и установка/восстановление Minecraft, loader, natives и собственного development JAR Space; основные пути проверены через окно. Подготовлено зашифрованное хранилище будущей Microsoft-сессии. Настоящий вход, владение игрой и запуск ещё не реализованы. Команда из корня: `npm.cmd run launcher`.

В dev-моде есть CPS со скользящим окном 1 секунда и событийный F8. Фактические проверки в мире и ограничения перечислены в [журнале проверок](docs/SMOKE-TEST.md). Задачи меню модулей и редактора HUD остаются в backlog.

## Порядок работы

Исследование и начальная проверка toolchain завершены. Каждый законченный результат оформляется отдельным содержательным коммитом и отправляется в main после проверки. Dev-мод не заменяет готовый клиент: Microsoft-вход, установка игры и HUD editor ещё не реализованы.

Название и оформление Space Client самостоятельные. Lunar Client, Badlion Client и ViperClient используются как продуктовые ориентиры.
