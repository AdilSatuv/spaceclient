# Space Client

Собственный Minecraft Java PvP-клиент и сайт. Автор: AdilSatuv.

Стадия на 23 октября 2026: первый игровой прототип, сайт на Next.js и API на NestJS. Пользовательского лаунчера и релиза пока нет.
Репозиторий: https://github.com/AdilSatuv/spaceclient

Сайт уже содержит главную, возможности с фильтрами, загрузки, журнал со статьями и помощь. Контентные разделы подключены к NestJS; отсутствие пользовательского релиза и отказ API различаются. Главная использует самостоятельные desktop/mobile иллюстрации. Figma-библиотека и полная матрица приёмки ещё в работе; публичного размещения пока нет.

Текущий приоритет — игровой клиент. В dev-мод добавлен CPS для левой и правой кнопок со скользящим окном 1 секунда; F8 обрабатывается по событиям клавиатуры. Фактические проверки в мире и оставшиеся ограничения перечислены в [журнале проверок](docs/SMOKE-TEST.md). Следующие этапы — меню модулей и редактор HUD.

## Порядок работы

Исследование и начальная проверка toolchain завершены. Каждый законченный результат оформляется отдельным содержательным коммитом и отправляется в main после проверки. Dev-мод не заменяет готовый клиент: Microsoft-вход, установка игры и HUD editor ещё не реализованы.

Название и оформление Space Client самостоятельные. Lunar Client, Badlion Client и ViperClient используются как продуктовые ориентиры.
