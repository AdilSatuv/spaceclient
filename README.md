Лаунчер получил backup/restore, безопасную диагностику и откат JAR/receipt, Windows setup — длинные пути. **530 тестов**, types/tokens/format, все сборки и совместная hidden/native QA прошли; [итог, исправления и ограничения](docs/WAVE2-REVIEW-2026-11-03.md), [QA JSON](docs/qa/wave2-2026-11-03.json), [контракт](docs/ACCOUNT-AND-COSMETICS-CONTRACT.md). Новые12 performance trials сохранены как короткие render-loop наблюдения, без обещания игрового FPS. Видимый сайт/аккаунт — http://127.0.0.1:50566/account; лаунчер открыт с новым bundle. Сайт уже содержит главную, возможности с фильтрами, загрузки, журнал со статьями и помощь. Контентные разделы подключены к NestJS; отсутствие пользовательского релиза и отказ API различаются. [Текущий дизайн Eclipse / Ringworld](docs/design/ECLIPSE.md) использует объёмный SVG-логотип, почти чёрный звёздный фон, медную планету и астероиды. Figma-библиотека и полная матрица приёмки ещё в работе; публичного размещения пока нет.

Локальный preview сайта и API: `npm.cmd run preview:web`. Оба процесса запускаются на свободных localhost-портах; ссылка появится в терминале. Публичная публикация отложена по выбору пользователя. В контенте обновлены статус профилей, прогресс лаунчера и инструкции; установщика и официального онлайн-входа пока нет.

Next.js использует FSD; сайт и NestJS разделяют контентные и аккаунтные контракты. Локальный вход по нику и настоящий запуск одиночной игры реализованы в [SC-25](docs/LOCAL-LAUNCH.md), Space-регистрация — в отдельном Account feature. Microsoft-вход отложен. Профили, память, диагностика Java и подготовка development-инстанса доступны без аккаунта. Команда из корня: `npm.cmd run launcher`; общий API по умолчанию — `npm.cmd run api` на localhost:3001.

В игре есть CPS со скользящим окном 1 секунда, событийный F8, меню правым Shift, 29 игровых и 26 HUD-модулей, редактор с двумя независимыми профилями, масштабом, привязками и импортом/экспортом. Проходят 272 Java-теста. Историческая приёмка SC-02/03/04/05 в мире — в [журнале](docs/SMOKE-TEST.md), [меню](docs/HUD-MODULES.md) и [редакторе](docs/HUD-EDITOR.md); границы проверки новых модулей и актуальная готовность — в [аудите](docs/READINESS-2026-11-03.md).

## Порядок работы

Каждый законченный результат оформляется отдельным содержательным локальным коммитом. Push в main и публичная публикация отложены по выбору пользователя. Локальный запуск и development setup не заменяют подписанный публичный релиз и официальный онлайн-вход. Историческая статическая серия и её ограничения — в [BENCHMARK.md](docs/BENCHMARK.md); новые измерения фиксируются отдельно, без переноса старых выводов на новый source tree.

Название и оформление Space Client самостоятельные. Lunar Client, Badlion Client и ViperClient используются как продуктовые ориентиры.
