# Space Client

Собственный Minecraft Java PvP-клиент и сайт. Автор: AdilSatuv.

Стадия на 24 октября 2026: игровой прототип, сайт Next.js/API NestJS и desktop-лаунчер с профилями, Java, установкой/восстановлением файлов и development JAR Space. Рабочего входа, запуска игры из лаунчера и публичного установщика пока нет.
Репозиторий: https://github.com/AdilSatuv/spaceclient

Сайт уже содержит главную, возможности с фильтрами, загрузки, журнал со статьями и помощь. Контентные разделы подключены к NestJS; отсутствие пользовательского релиза и отказ API различаются. Главная использует самостоятельные desktop/mobile иллюстрации. Figma-библиотека и полная матрица приёмки ещё в работе; публичного размещения пока нет.

Локальный preview сайта и API: `npm.cmd run preview:web`. Оба процесса запускаются на свободных localhost-портах; ссылка появится в терминале. Публичная публикация отложена по выбору пользователя. В контенте обновлены статус профилей, прогресс лаунчера и инструкции; установщика и рабочего входа пока нет.

Текущий приоритет — архитектура вебсайта. Next.js переведён на FSD с публичными API слайсов; сайт и NestJS используют общий пакет контентных контрактов. Backend разделён на HTTP, прикладной сервис и хранилище. Для лаунчера временно выбраны собственная регистрация Space и вход по нику; реализация ещё впереди, Microsoft-вход отложен. Уже работают профили, память, диагностика Java и подготовка development-инстанса. Команда из корня: `npm.cmd run launcher`.

В dev-моде есть CPS со скользящим окном 1 секунда и событийный F8. Фактические проверки в мире и ограничения перечислены в [журнале проверок](docs/SMOKE-TEST.md). Задачи меню модулей и редактора HUD остаются в backlog.

## Порядок работы

Исследование и начальная проверка toolchain завершены. Каждый законченный результат оформляется отдельным содержательным коммитом и отправляется в main после проверки. Dev-мод не заменяет готовый клиент: рабочий вход, запуск из лаунчера и HUD editor ещё не реализованы.

Название и оформление Space Client самостоятельные. Lunar Client, Badlion Client и ViperClient используются как продуктовые ориентиры.
