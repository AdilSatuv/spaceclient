# Space Client

Собственный Minecraft Java PvP-клиент и сайт. Автор: AdilSatuv.

Стадия на 24 октября 2026: игровой прототип, сайт Next.js/API NestJS и desktop-лаунчер с профилями, Java, установкой/восстановлением файлов и development JAR Space. Добавлен локальный ник и запуск одиночной игры из лаунчера (SC-25). Space-регистрации, Microsoft-входа и публичного установщика пока нет.
Репозиторий: https://github.com/AdilSatuv/spaceclient

Сайт уже содержит главную, возможности с фильтрами, загрузки, журнал со статьями и помощь. Контентные разделы подключены к NestJS; отсутствие пользовательского релиза и отказ API различаются. [Текущий дизайн Eclipse / Ringworld](docs/design/ECLIPSE.md) использует объёмный SVG-логотип, почти чёрный звёздный фон, медную планету и астероиды. Figma-библиотека и полная матрица приёмки ещё в работе; публичного размещения пока нет.

Локальный preview сайта и API: `npm.cmd run preview:web`. Оба процесса запускаются на свободных localhost-портах; ссылка появится в терминале. Публичная публикация отложена по выбору пользователя. В контенте обновлены статус профилей, прогресс лаунчера и инструкции; установщика и официального онлайн-входа пока нет.

После доступных локальных задач сайта работа переходит к лаунчеру и HUD. Next.js переведён на FSD; сайт и NestJS используют общий пакет контентных контрактов. Backend разделён на HTTP, прикладной сервис и хранилище. Для лаунчера выбран локальный вход по нику: сохранение и настоящий запуск одиночной игры реализованы в [SC-25](docs/LOCAL-LAUNCH.md). Space-регистрация остаётся отдельным срезом, Microsoft-вход отложен. Уже работают профили, память, диагностика Java и подготовка development-инстанса. Команда из корня: `npm.cmd run launcher`.

В игре есть CPS со скользящим окном 1 секунда, событийный F8, меню модулей правым Shift и редактор HUD с двумя независимыми профилями, масштабом, привязками и импортом/экспортом. SC-02/03/04/05 приняты в настоящем мире, включая 720p/1080p, миграцию и перезапуск; 36 Java-тестов проходят. Свидетельства — в [журнале](docs/SMOKE-TEST.md), [меню](docs/HUD-MODULES.md) и [редакторе](docs/HUD-EDITOR.md).

## Порядок работы

Исследование и начальная проверка toolchain завершены. Каждый законченный результат оформляется отдельным содержательным коммитом и отправляется в main после проверки. Локальный запуск не заменяет готовый релиз: Space-регистрация, официальный онлайн-вход и установщик ещё не реализованы. Для SC-13 собраны девять локальных captures и дополнительные проверки совместимости. Результаты разведочной статической серии и её ограничения — в [BENCHMARK.md](docs/BENCHMARK.md); startup timing и полный официальный baseline ещё не приняты.

Название и оформление Space Client самостоятельные. Lunar Client, Badlion Client и ViperClient используются как продуктовые ориентиры.
