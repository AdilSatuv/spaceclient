## Порядок работы

Сначала изучение материала и ТЗ, затем проверка инструментов, технический эксперимент с Minecraft 1.8.9 и реализация. Каждый законченный результат оформляется отдельным содержательным коммитом и отправляется в main после проверки. Сборок и работающего игрового клиента пока нет.

Название и оформление Space Client самостоятельные. Lunar Client, Badlion Client и ViperClient используются как продуктовые ориентиры.
