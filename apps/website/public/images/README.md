# Space Client artwork

`space-hero-v2.png` — original generated environment artwork prepared for the new Space Client website/Figma design on 23 October 2026. Generated with the built-in image generation tool from an original prompt: midnight block-built floating islands, ruins, blue planetary eclipse, violet nebula and dark left-side space for the headline.

This is illustrative concept artwork, not a screenshot of the working Minecraft client and not an asset downloaded from Lunar, Badlion or Viper. It contains no UI/text/metrics. In Figma it should be one discrete background image; text, navigation, controls and HUD are separate editable Design layers.

The original PNG is 1672 × 941, 2,055,170 bytes. Website delivery should use responsive image optimization; do not turn the entire web page into a raster image.

`space-hero-mobile-v1.png` — portrait 9:16 variant generated with the built-in image tool on 23 October 2026, using the desktop artwork as a reference. Original generated PNG copied into this directory; no CLI/API key was used. It is selected through a native picture source and Next.js getImageProps at <=760 px, so the browser chooses one hero asset. The desktop image remains unchanged.

Mobile prompt: "Create a portrait 9:16 mobile hero background variant of the referenced original Space Client night-world illustration. Recompose this same floating block-world; preserve midnight navy, ice blue, restrained violet, cubic ruins, pines, waterfalls and luminous eclipsed planet. Top 50 percent: calm dark night sky with space for headline and buttons. Lower half: planet around lower-right middle, ruined islands and stone arch on bottom-right. No text, logos, HUD, buttons, watermark or UI screenshot. Do not simply crop the wide reference."
